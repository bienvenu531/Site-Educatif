1Premier programme, variables et types

Un programme Python s'écrit dans un fichier dont le nom se termine par .py, ou directement dans une console interactive. La fonction print affiche un résultat. Les blocs sont délimités par l'indentation : quatre espaces en début de ligne.

python
# Mon premier programme
        nom = "Ada"
        age = 36
        print("Bonjour", nom, "!")
        print("Dans deux ans, j'aurai", age + 2, "ans.")

Une variable est un nom associé à une valeur. On distingue les types principaux : int pour un entier, float pour un réel, str pour une chaîne de caractères et bool pour un booléen, True ou False.

La fonction input renvoie toujours une chaîne : pour obtenir un nombre, il faut convertir avec int ou float, par exemple age = int(input('Quel âge ? ')).

Les opérateurs usuels sont +, −, *, /, // pour la division entière, % pour le reste et ** pour la puissance. Attention : / renvoie toujours un réel, donc 6 / 3 vaut 2.0 et non 2.

TypeExempleRemarque
int42opérations entières
float3.14résultat approché
str« bonjour »concaténation avec +
boolTrue, Falselié à and, or, not

À retenir

En Python, l'indentation de quatre espaces définit les blocs. Le signe = affecte une valeur, tandis que == teste une égalité.

2Conditions et boucles

Une instruction conditionnelle exécute un bloc si une condition est vraie, un autre sinon. On écrit if, elif et else, suivis de deux-points et d'un bloc indenté. Les comparaisons sont ==, !=, <, >, <= et >= ; on peut les combiner avec and, or et not.

python
age = int(input('Quel âge as-tu ? '))
        if age >= 18:
            print("Tu es majeur.")
        elif age >= 13:
            print("Tu es adolescent.")
        else:
            print("Tu es un enfant.")

La boucle for parcourt une séquence. La fonction range(1, 11) produit les entiers de 1 à 10 inclus. La boucle while répète un bloc tant qu'une condition reste vraie.

python
total = 0
        for n in range(1, 11):
            total = total + n
        print(total)  # 55

Dans une boucle while, il faut modifier la variable testée, sinon la boucle ne s'arrête jamais. L'instruction break permet de sortir immédiatement d'une boucle.

python
n = 1
        while n <= 64:
            n = n * 2
        print(n)  # 128

Exemple guidé

Déroulons la boucle while ci-dessus. Étape 1 — n vaut 1, la condition 1 <= 64 est vraie, n devient 2. Étape 2 — 2 <= 64 est vraie, n devient 4. Étape 3 — la valeur double à chaque tour : 8, 16, 32, puis 64. Étape 4 — 64 <= 64 est encore vraie, n devient 128 ; la condition 128 <= 64 est fausse, la boucle s'arrête et print affiche 128.

À retenir

for parcourt une séquence connue ; while répète tant qu'une condition est vraie. Le bloc indenté doit faire évoluer la condition vers la fin de la boucle.

3Fonctions et listes

Une fonction regroupe des instructions sous un nom. On la définit avec def, on indique ses paramètres entre parenthèses, et on renvoie un résultat avec return. Une fonction sans return renvoie None.

python
def moyenne(notes):
            """Renvoie la moyenne d'une liste de nombres."""
            if len(notes) == 0:
                return None
            return sum(notes) / len(notes)

        notes = [12, 15, 9, 17]
        print(moyenne(notes))  # 13.25

Une liste est une suite ordonnée de valeurs, écrite entre crochets : notes = [12, 15, 9, 17]. Les indices commencent à 0 : notes[0] vaut 12 et notes[-1] vaut 17. La fonction len donne la longueur, et notes[1:3] découpe un sous-ensemble.

ExpressionRésultat
notes[0]12
notes[-1]17
len(notes)4
notes[1:3][15, 9]
sum(notes)53
max(notes)17

On peut construire une liste vide puis l'alimenter : resultats = [] puis resultats.append(15). La méthode append ajoute un élément en fin de liste.

Une fonction se documente avec une docstring entre triples guillemets, placée juste après la ligne def. Elle explique ce que fait la fonction et aide les autres programmeurs à la réutiliser.

4Un exemple complet

Construisons un programme qui compte les notes supérieures ou égales à 10.

python
notes = [12, 8, 15, 9, 17]
        admis = 0
        for note in notes:
            if note >= 10:
                admis = admis + 1
        print("Notes au-dessus de 10 :", admis)  # 3

La variable admis démarre à 0. À chaque tour, la condition note >= 10 est testée ; quand elle est vraie, admis augmente de 1. À la fin, admis vaut 3, car 12, 15 et 17 dépassent 10.

  1. Lire l'énoncé et reformuler ce qui est demandé.
  2. Identifier les entrées, les sorties et les contraintes.
  3. Écrire l'algorithme en pseudo-code.
  4. Coder en Python, en respectant l'indentation.
  5. Tester : cas normal, cas limite, liste vide.

Les erreurs fréquentes sont l'oubli d'indentation, l'usage de = au lieu de == et les conversions oubliées après input. Python affiche un message qui indique la ligne fautive : il faut le lire avant de corriger.

À retenir

Un programme se construit par étapes : écrire, exécuter, tester, corriger. Les messages d'erreur indiquent la ligne à relire.
